# garam-agent-operator

This repository moved into [garamsh/garam-bot](https://github.com/garamsh/garam-bot) under `operator/`, with its full history, and is archived (garamsh/garam-bot#1205).

- **Code:** the operator is the module `github.com/garamsh/garam-bot/operator` at [`operator/`](https://github.com/garamsh/garam-bot/tree/dev/operator).
- **Interface:** the cluster-connection interface is at [`api/cluster-connection/v1alpha1/`](https://github.com/garamsh/garam-bot/tree/dev/api/cluster-connection/v1alpha1).
- **Docs:** the architecture documents and the decision log are at `operator/docs/architecture/`, and keep their numbers.
- **Issues:** the open issues were transferred to garamsh/garam-bot, and their old links redirect.
- **Releases:** new releases are tagged `operator/v<version>` there, and publish to `garam-bot/operator-*` (garam-bot ADR 0041). The tags `v0.1.0-dev.1` to `v0.1.0-dev.5` stay here.

The commit hashes here differ from those in garam-bot, because the history was rewritten into `operator/`. A record that names a commit of this repository reads it here.
